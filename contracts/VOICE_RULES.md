## Scope (unchanged from v1.0)

The gospel binds every word a user reads in Bloviate's app chrome:
labels, setting descriptions, buttons, empty states, errors,
notifications, onboarding, paywall copy, dialog text — plus release and
store copy (`RELEASE.md` routes its copy rules here).

Bloviate's personas get a pass on output and output only. A persona is
a character; its output is character work. Bloviate's own screens get
no pass: a settings label in Bloviate talks the same way a settings
label in Stratum talks.
